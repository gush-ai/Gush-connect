# Contributing to Gush Connect

Thank you for helping expand the **Gush Connect** ecosystem! We welcome contributions from developers worldwide to build custom connectors, improve SDKs, and expand documentation.

---

### How to Contribute

1.  **Report Issues**: Use GitHub Issues to submit bug reports or propose new features.
2.  **Submit Pull Requests**:
    *   Fork the repository.
    *   Create a topic branch (`git checkout -b feature/my-new-connector`).
    *   Commit your changes with descriptive messages.
    *   Push to the branch and open a Pull Request.

---

### Code Standards

*   Ensure code is 100% runnable, formatted, and contains no placeholders.
*   Avoid exposing hardcoded API credentials or secret tokens in example code.
*   Add unit tests or usage examples for new functions.
